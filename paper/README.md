# 종이 청첩장 · 식권

모바일 청첩장(저장소 루트 `index.html`)과 별도로, 인쇄용 디자인을 이 폴더에서 관리합니다.

| 파일 | 내용 | 인쇄 크기 |
|---|---|---|
| `png/outside.png` | 청첩장 바깥면 (왼쪽 뒷표지, 오른쪽 앞표지) | 250×175mm, 접으면 125×175mm |
| `png/inside.png` | 청첩장 안쪽면 (왼쪽 인사말, 오른쪽 달력·예식 안내) | 250×175mm |
| `png/ticket.png` | 식권 | 90×50mm |

PNG는 300dpi입니다. 가운데 세로선이 접는 선입니다.

## 수정하는 법

- 문구와 배치는 `src/*.html`에서 고칩니다.
- 색은 `src/style.css`의 `--accent` 한 줄만 바꾸면 전체에 적용됩니다.
- 수정한 뒤 `python3 paper/render.py`를 실행하면 `png/`가 다시 만들어집니다.

## 인쇄 전 확인

- 인쇄소가 요구하는 재단 여백(보통 사방 2~3mm)과 파일 형식(PDF, CMYK 등)을 확인합니다.
- 폰트는 고운바탕(한글)과 Cormorant Garamond(영문)입니다. 둘 다 Google Fonts의 OFL 폰트입니다.
